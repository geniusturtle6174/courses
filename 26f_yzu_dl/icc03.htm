In-class Competition III

Problem Desc

Decode the Captcha.

驗證碼規格為四位數字，大小為高度 28 像素，寬度 112 像素，只有一個通道；由完整的 MNIST 資料集當中取樣，進行裁剪、旋轉與拼接，以及加上一些模糊和干擾而成。各位可以自行產生合乎前述的圖片來訓練模型參加比賽，課程方面也會在 Portal 討論區上，提供圖片產生的範例程式。

The captcha is a four-digit number. The image is 28 pixels high and 112 pixels wide, with one channel. It is made by sampling from the full MNIST dataset, then cropping, rotating, and joining the digits, and adding some blur and noise. You can generate images that meet this description yourself to train your model for the competition. The course will also provide example code for generating the images on the Portal discussion board.

模型的規格限制如下：

The model specifications are as follows:

  • 輸入形狀為 (batch, ch=1, h=28, w=112)，資料型別為 float32，數值範圍為 [0, 255]，即 MNIST 資料集原圖的範圍。請留意，課程提供的產圖程式，輸出沒有通道軸，你需要自己在餵給模型之前加入該軸。
  • The input shape is (batch, ch=1, h=28, w=112), the data type is float32, and the value range is [0, 255], which is the range of the original MNIST images. Please note that the output of the image generation code provided by the course has no channel axis, so you need to add that axis yourself before feeding it to the model.
  • 輸出形狀為 (batch, n_digits=4, n_class=10)，其中 n_digits 依序代表由左至右的四位數字。課程方面會以 np.argmax(output, axis=-1) 的方式，將模型的原始輸出，轉為驗證碼的辨識結果。
  • The output shape is (batch, n_digits=4, n_class=10), where n_digits stands for the four digits from left to right, in order. The course will convert the raw output of your model into the captcha recognition result with np.argmax(output, axis=-1).
  • 參數量在 5M 以內，每張圖推論時的運算量在 200M FLOPs 以內。如果你的模型在教師或助教的電腦上被主觀認為跑太久，則首先會依此條規格被檢視。課程方面將提供參數量和運算量的計算程式供參考。
  • The number of parameters must be within 5M, and the computation for each image during inference must be within 200M FLOPs. If the instructor or a TA subjectively thinks your model runs too long on their computer, it will first be checked against this specification. The course will provide code for calculating the number of parameters and the computation, for your reference.
  • 不得限定執行的 device；繳送的 model.pth 在儲存前，須先將模型參數搬至 cpu。
  • You may not restrict which device the model runs on. Before saving the submitted model.pth, you must move the model parameters to the cpu.
  • 不得使用 PyTorch 版本超過 2.11.0 才有的任何模組或函式，且不得使用 torch.compile、torch.export、torch.jit、torch.hub。
  • You may not use any module or function that only exists in PyTorch versions newer than 2.11.0, and you may not use torch.compile, torch.export, torch.jit, or torch.hub.
  • Class 名稱必須為 MODEL，建構時不得帶入任何參數。
  • The class name must be MODEL, and it must not take any arguments when constructed.
  • 整體的評分程式會在 Portal 上提供，你的模型必須能被該程式載入並使用。
  • The overall grading code will be provided on the Portal, and your model must be loadable and usable by that code.

Grading Policy

    • 以評分程式的 Digit accuracy 和 String accuracy 兩者平均來採計。
    • The average of Digit accuracy and String accuracy from the grading code is used.

    • The number of images generated with the default configuration of the image generation code makes up half of all the grading data. The other levels of noise and numbers of images are not guaranteed.
  • 遲交但能準時參加 demo 者，分數八折給予；有繳交但未參加展示者，分數六折給予。遲交且未能準時參加 demo 者不給分
  • If you submit late but attend the demo on time, your score will be multiplied by 0.8; if you submit but do not attend the demonstration, your score will be multiplied by 0.6. If you submit late and fail to attend the demo on time, you will receive no score.
