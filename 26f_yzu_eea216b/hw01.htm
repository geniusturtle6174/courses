Problem Desc

本題自 LeetCode 的 1. Two Sum 修改而來。與 LeetCode 原版題目不同之處如下（其餘細節請遵循原版題目）：

This problem is modified from LeetCode 1. Two Sum. The differences from the original LeetCode problem are listed below. For other details, please follow the original problem:

  1. 恰有一組解時，請回傳一個串列，內容為那兩個元素的索引值，其中索引值較小者，其索引值應出現在回傳串列的前面。例如串列為 [1, 2, 3, 4] 而目標值為 7 時，應回傳 [2, 3] 而非 [3, 2]。
  2. When there is exactly one solution, return a list with the indices of the two elements. The smaller index should come first in the returned list. For example, if the list is [1, 2, 3, 4] and the target is 7, you should return [2, 3], not [3, 2].
  3. 存在多組解時，索引值小的要盡量先使用。例如串列為 [1, 2, 3, 4] 而目標值為 5 時，應回傳 [0, 3] 而非 [1, 2]。又，串列為 [3, 3, 3, 3] 而目標值為 6 的時候，應回傳 [0, 1] 而非其他任何內容。
  4. When there are multiple solutions, try to use the smaller index first. For example, if the list is [1, 2, 3, 4] and the target is 5, you should return [0, 3], not [1, 2]. Also, if the list is [3, 3, 3, 3] and the target is 6, you should return [0, 1], not anything else.
  5. 不存在解時，請回傳 [-1, -1]。
  6. When there is no solution, return [-1, -1].
