Problem Desc

This problem is modified from LeetCode 1. Two Sum. The differences from the original LeetCode problem are listed below. For other details, please follow the original problem:
  1. When there is exactly one solution, return a list with the indices of the two elements. The smaller index should come first in the returned list. For example, if the list is [1, 2, 3, 4] and the target is 7, you should return [2, 3], not [3, 2].
  2. When there are multiple solutions, try to use the smaller index first. For example, if the list is [1, 2, 3, 4] and the target is 5, you should return [0, 3], not [1, 2]. Also, if the list is [3, 3, 3, 3] and the target is 6, you should return [0, 1], not anything else.
  3. When there is no solution, return [-1, -1].
