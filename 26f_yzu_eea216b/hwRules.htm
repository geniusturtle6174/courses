• 本課程之所有作業都需要向教師或助教 demo。Demo 時，需解釋程式與回答問題，視回答狀況給分。
  • 作業 demo 說明與規定
    • 時間：指定週次之週二課堂時間，並視情況使用當週三時間。
    • 地點：原上課時間在該日各自的原上課教室。
    • 方式：教師或助教依公布之順序叫號，同學到教師或助教座位旁進行說明。
    • 當週未能 demo 者：
      • 若因時間拖延，致使有人未被輪到，則準時繳交者，皆不影響作業分數。
      • 若是輪到 demo 但未能前來（包含但不限於當天請假），則處理方式另訂。
  • 教師主觀認定有下列現象者，將影響作業分數
    • 註解量過多。
    • 將測資寫死在程式碼當中（重要邊界條件除外，例如費氏數列的前兩項）。
    • Demo 回答提問之內容錯誤。
    • Demo 回答提問時猶豫過久。
    • 未遵守本頁面其他規定，或各次作業之規定。
    • 其餘任何試圖影響批改程序進行或批改公平性之行為。
  • 學號前三碼小於等於 113 者，除另有公告外，僅得找教師 demo。
  • 程式碼必須撰寫於副檔名為 py 的純文字檔，並讓 Python 直接執行該文字檔。其他任何方式，包含但不限於開啟 Python 後逐行輸入者，或者使用 Jupyter Notebook 者，教師得不給予分數。
  • 除題目允許外，禁止以「import」或其他任何方式載入函式庫。
  • 若遇有數學符號、程式片段或題目敘述等方面之顯示差異，以課程網頁在 Windows 電腦版的 Chrome 或 Edge 瀏覽器最新版開啟時之顯示效果為準。
  • 若遇有語法執行結果，可能在不同作業系統與 Python 版本之間有差異時，以 Win10 的 Python 3.12.6 (64-bit) 為準。
  • 任何影響作業分數之具體折扣，在不同次作業很可能會有不同標準。
  • 若各別作業之規則跟上述內容相異時，依各別之規則為準。
