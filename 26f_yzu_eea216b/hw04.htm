Problem Desc

學校正在舉辦⼀場⼤型活動，共有 n 位學⽣參加，學⽣編號為 1 到 n。活動開始時，所有學⽣按照編號由⼩到⼤排成⼀列，即 1, 2, 3, ..., n；而活動進⾏期間，老師會不斷調整學⽣的排列順序，調整的方式有以下兩種：

The school is holding a large event with n students, numbered 1 to n. At the start, all students line up in order of their numbers from smallest to largest, i.e. 1, 2, 3, ..., n. During the event, the teacher keeps rearranging the students in one of the following two ways:

  • move x y：將編號為 x 的同學，移動到編號為 y 的同學的後面。若 x 和 y 當中有任一人不在隊伍中，則忽略此動作。
  • move x y: Move student x to right behind student y. If either x or y is not in the line, ignore this operation.
  • remove x：將編號為 x 的同學移出隊伍。若 x 不在隊伍中，則忽略此動作。
  • remove x: Remove student x from the line. If x is not in the line, ignore this operation.

請撰寫一個函式 line_management，輸入是一開始的同學人數 n 和調整內容 ops，輸出將所有調整依序執行完畢以後，指向隊伍開頭同學的節點指標。

Please write a function line_management. The input is the initial number of students n and the list of adjustments ops. The output is the node pointer pointing to the student at the front of the line after all adjustments have been executed in order.

Input Desc

  • n (number of people): positive integer.
  • 調整內容 ops：list of tuples，每個 tuple 為以下其中一種： Adjustments ops: a list of tuples. Each tuple is one of the following:
    • ("move", x, y): x and y are positive integers.
    • ("remove", x): x is positive integer.

Output Desc

將隊伍中的每位同學，依序用 linked list 連接起來，並回傳指向隊伍開頭同學的節點指標，若隊伍已無人請回傳 None。每個節點應至少包含下列屬性：

Link every student in the line in order using a linked list, and return the node pointer pointing to the student at the front of the line. If no one is left in the line, return None. Each node should have at least the following attributes:

  • val：同學的編號。
  • val: The student's number.
  • next：指向代表下一位同學的節點指標。隊伍尾端的同學，此指標應指向 None。
  • next: The pointer to the node of the next student. For the student at the end of the line, this pointer should point to None.

Sample Input

n = 10, ops = [('move', 3, 5), ('remove', 4), ('move', 2, 10), ('remove', 1)]

Sample Output

5, 3, 6, 7, 8, 9, 10, 2
