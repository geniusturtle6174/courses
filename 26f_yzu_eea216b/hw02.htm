Problem Desc

Some numbers can be made by putting some operators between 1, 1, 4, 5, 1, 4. For example, 29 equals 1 - 1 + 4 + 5 * ( 1 + 4 ) and 2029 equals -1 + 145 * 14, but 8964 cannot be made this way. In this problem, you need to write a function iiyokoiyo. The input is a non-negative integer. The output is a boolean value indicating whether this input can be made by inserting some operators between 1, 1, 4, 5, 1, 4.

Input Desc

A nonnegative integer less than or equal to 114514.

Output Desc

Return "True" if the input number can be decomposed into an arithmetic expression made from the digits 1, 1, 4, 5, 1, 4. Return "False" otherwise.

Sample Input

29

Sample Output

"True"
